Mode Offline - data hanya tersimpan di HP ini. Agar data otomatis sama di semua HP / laptop, sambungkan penyimpanan online-nya dengan langkah berikut (cukup sekali saja):
  1. Buka console.firebase.google.com -> proyek dealy-riport
  2. Menu Build -> Firestore Database -> Create database (pilih Start in production mode, lokasi bebas, mis. singapore)
  3. PENTING: pilih menu yang bertuliskan "Firestore Database", BUKAN "Realtime Database".
    Cek judul besar di atas halaman setelah masuk: harus tertulis Firestore Database. Kalau tertulis Realtime Database, itu menu yang salah - rules di bawah akan gagal dengan tulisan merah "Parse error" seperti yang terjadi sebelumnya. Kembali ke menu lalu pilih Firestore Database.
  4. Tab Rules -> hapus semua isinya -> ganti menjadi (boleh di-copy persis):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

lalu klik tombol Publish yang berada di kanan atas area rules.

  1. Muat ulang halaman ini - tulisan akan berubah jadi Terhubung

INPUT LAPORAN

Isi data laporan unit. KONTRAK & STATUS terisi otomatis setelah NO POLISI dipilih. Data langsung sama di semua HP.

REKAP LAPORAN 0 data

Rekap tersimpan permanen dan dikelompokkan per KONTRAK (ada baris pembatas berwarna, sama seperti Antrian DO). Setiap baris bisa dikirim lewat WhatsApp, diedit, atau dihapus.

ANTRIAN DO 0 unit

Ambil no polisi dari chat grup WhatsApp: buka grup -> salin (copy) pesan-pesannya -> tempel (paste) di kotak -> klik AMBIL NO POLISI -> muncul pratinjau centang -> SIMPAN. Aturan status: baris ada kata masuk -> LOADING; tidak ada kata masuk -> ANTRIAN DO (boleh diubah manual di tabel). No polisi yang disimpan otomatis masuk ke Daftar No Polisi juga - kontraknya diisi menyusul saat input laporan.
