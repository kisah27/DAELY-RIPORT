⚠ Mode Lokal — data hanya tersimpan di perangkat ini. Agar data otomatis sama di semua orang (HP / laptop), aktifkan Firebase Firestore:
  1. Buka console.firebase.google.com → proyek dealy-riport
  2. Menu Build → Firestore Database → Create database (pilih Start in production mode, lokasi bebas, mis. singapore)
  3. PENTING: pilih menu yang bertuliskan "Firestore Database", BUKAN "Realtime Database".
    Cek judul besar di atas halaman setelah masuk: harus tertulis Firestore Database. Kalau tertulis Realtime Database, itu menu yang salah — rules di bawah akan gagal dengan tulisan merah "Parse error" seperti yang terjadi sebelumnya. Kembali ke menu ☰ lalu pilih Firestore Database.
  4. Tab Rules → hapus semua isinya → ganti menjadi (boleh di-copy persis):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}

lalu klik tombol Publish yang berada di kanan atas area rules.

  1. Refresh halaman ini — tulisan akan berubah jadi 🟢 Terhubung
